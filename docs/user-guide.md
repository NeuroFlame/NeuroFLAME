# NeuroFLAME user guide

## Agent access

NeuroFLAME can be managed through an optional MCP connection. It is disabled by
default and can be controlled from **User Settings → Agent access (MCP)**. Read
the [MCP service guide](./mcp-service.md) before connecting an agent, especially
the boundary between protected local source data and the separately enabled,
deidentified derivatives already shown by the Results page.
